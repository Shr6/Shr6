### 🚀 Projects

**🌐 [Portfolio Website](https://github.com/Shr6/portfolio-website)**
My personal portfolio site — multi-page React app (Home, About, Experience, Projects, Skills, Contact). Built with **React** + **Vite**, deployed via GitHub Pages on a custom domain. → [Live site](https://shrijanpokharel7.com.np)

**🚦 [AI Traffic Simulator](https://github.com/Shr6/AI-traffic-signal)**
Multi-lane junction simulator with an adaptive AI signal controller. Vehicles navigate a four-way intersection controlled by a real-time queue scoring algorithm. Built with **Python** + **Pygame**.

**📚 [Loksewa Buddy Prep](https://github.com/Shr6/loksewa-buddy-prep)**
Web platform for Nepal Public Service Commission (Loksewa) exam preparation. Built with **TanStack Start**, **React 19**, **shadcn/ui**, **Tailwind CSS**. → [Live site](https://shr6.github.io/loksewa-buddy-prep/)

**🌊 [Flood Monitoring System](https://github.com/Shr6/hackathon)**
Arduino-powered flood monitor with real-time data visualization, a Flask web dashboard, historical logging, and CSV export. Built with **Arduino**, **Python**, **Flask**, **HTML**.

**📊 [Quantium Starter — Data Analytics Internship](https://github.com/Shr6/quantium-starter-repo)**
Data processing and analysis project completed as part of the Quantium virtual internship program. Built with **Python** for data cleaning, transformation, and analysis.
